Description

JSON serialisation instances for timeseries query results. The format closely follows the Prometheus HTTP API: result types are named "scalar", "vector", "matrix"; timestamps are Unix seconds (Double); durations are seconds (Double). Import this module to bring the instances into scope; it exports nothing itself.
