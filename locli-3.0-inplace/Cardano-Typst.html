typstEscape :: Text -> Text Source #

Escape text for verbatim display inside a Typst content block [...]: every character Typst markup could interpret is backslash-escaped, so data values (run names, filter descriptions, "---", ...) display exactly as given. Apply to data only, before adding any intended markup.
