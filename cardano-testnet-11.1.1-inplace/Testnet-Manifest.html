supportedSchemaVersion :: Int Source #

The manifest schema version this code writes and reads. Any change to the manifest shape bumps it (see the schema's policy note).

File operations

writeManifest :: FilePath -> Manifest -> IO () Source #

Write the manifest atomically: write to a temp file in the same directory, then rename. A reader never sees a half-written file. If writing fails, the temp file is removed rather than left behind.

removeStaleManifest :: FilePath -> IO () Source #

Delete any pre-existing manifest in the output directory (fresh-run rule).

Manifest construction

buildManifest Source #

Arguments

:: FilePath

Output directory (the tmpAbsPath inside cardanoTestnet)

-> TestnetRuntime

The runtime returned after readiness checks pass

-> AnyCardanoEra

The era the testnet runs in

-> UTCTime

System start time (from the shelley genesis, potentially updated)

-> IO Manifest 

Build a manifest from the data available after the testnet is ready.

The era is passed in because cardanoTestnet does not receive it as a parameter — both CLI paths (creation and node-env) go through it. For now the only supported era is Conway (defaultEra).

makeManifestRelPath :: FilePath -> FilePath -> FilePath Source #

Make a path relative to the output directory, normalised (no leading ./).

Windows named pipes (\.pipe...) come through unchanged without a special case: splitDrive treats @\.@ as a drive, so makeRelative returns pipe paths as-is and normalise keeps the prefix (checked on filepath 1.4.301.0, both the Windows and Posix flavours).
