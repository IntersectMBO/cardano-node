newtype SubmissionEndpoint Source #

A fully-specified submission endpoint: a backend protocol together with the endpoint it addresses. A protocol cannot occur without an endpoint, so code past config resolution never needs to handle that combination. Each future backend adds a constructor carrying exactly the connection configuration it needs (turning this into a plain data then).

newtype EndpointUri Source #

A submission endpoint address, well-formed by construction: decoding only accepts absolute URIs (a scheme is required, e.g. ws://host:1337). Which schemes are meaningful is for each backend to decide.
