runCheckStatusOptions :: HasCallStack => CheckStatusOptions -> IO () Source #

Run the status command: print the report (a table, or JSON) on stdout and exit with 0 (running or degraded), 3 (stalled), 4 (stopped) or 5 (no testnet). When the manifest or the genesis file cannot be read, print the error on stderr and exit with 1.

checkStatus :: HasCallStack => FilePath -> Nat -> IO StatusReport Source #

Check the testnet in the given output directory. Each node gets the given number of seconds to answer, and all nodes are asked at the same time. It throws when the check itself fails: when the manifest, or the shelley genesis it points to, cannot be read.

newestTip :: [TipInfo] -> Maybe TipInfo Source #

The rule for the best tip: the newest one, which is the one with the highest slot. The ages cannot tell: each age is measured when its node answered, and the nodes answer at different times.
