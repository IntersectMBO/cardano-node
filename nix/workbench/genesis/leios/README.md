# A pregenerated Leios voting key

`bls.skey` is the BLS signing key a forger votes with, and `bls-key.json` is the
matching registration: the public key plus a proof that whoever registered it
holds the secret. `derive-from-cache-jq` writes that object onto the genesis
stake pools, so the pool the workbench creates comes with a voting key and the
Leios committee has a member that can sign.

The two files are one pair. The proof is a signature by the signing key over its
own public key, under a domain-separation tag reserved for the purpose, so it
verifies only against the key it came from. `mkLeiosCommittee` drops a key whose
proof fails without saying so -- the seat stays, minus its key -- and a run that
cannot vote certifies no endorser block and looks exactly like a run with Leios
switched off. So replace neither file alone.

## Why it is pregenerated

A pool's voting key would naturally come from `create-testnet-data`, which makes
every other key the pool has. It sets `sppBlsKey` to nothing, and the
`cardano-cli` this branch builds against has no command that would produce a
proof of possession anyway.

Generating one per genesis would also mean generating it per *cache entry*: the
key would live inside the entry, every existing entry would lack it, and the
layout version would have to be bumped to throw them all away -- a staked
genesis is hundreds of megabytes and slow to rebuild. A key that is fixed and
patched in at derive time costs no entry, since `derive-from-cache-jq` runs on
every run, cache hit or miss.

## This key is not a secret

It is checked in, so everyone has it. That is the same bargain the rest of a
workbench genesis makes: the stake keys are generated by a function that says it
is not cryptographically secure, pools pledge nothing, and millions of UTxOs
exist to pad a file. None of it protects anything, and none of it may be used
anywhere that does.

The pair is the one from `ouroboros-consensus`, at
`ouroboros-consensus-cardano/test/tools-test/disk/queue-config`, where a chain
built on it certifies endorser blocks -- which is what makes it worth reusing
rather than minting a new one that has never been shown to work.
